# 🛡️ nedestroyme

> **Умная, бесшумная ловушка для смартфона с мгновенным алертом в Telegram и нулевым расходом батареи.**

В отличие от коммерческих аналогов (CrookCatcher, Lockwatch и др.), **nedestroyme** не содержит рекламы, трекеров и аналитики. Приложение **не висит в фоне** и не расходует батарею: оно активируется операционной системой исключительно в момент ввода неверного пароля или графического ключа, фиксирует злоумышленника и мгновенно выгружается из памяти.

---

## ⚡ Особенности и возможности

* **🔋 0% фоновой нагрузки:** Приложение спит по системному событию `DeviceAdminReceiver`. Пока телефон не трогают — расход процессора, камеры и батареи равен ровно **0.00%**.
* **📸 / 📹 Фото или умное видео:**
    * Режим серии фото (от 1 до 5 снимков с интервалом в 1 сек для разных ракурсов).
    * Режим умного скрытого видео со звуком (5–10 сек), таймер которого автоматически продлевается при каждой новой попытке подбора пароля.
* **🔘 Кнопка вкл/выкл:** Индикатор работы прямо на главном экране (зеленый — защита активна, красный — отключена).
* **📍 Точный GPS-трекинг:** Непрерывный поиск спутников во время съемки, обратное геокодирование адреса (улица/город) и прямая ссылка на Maps.
* **✈️ Telegram-оповещения:** Мгновенный отчет с координатами, числом попыток и медиафайлом (одно полное аккуратное сообщение).
* **🔍 Широкий угол:** Автоматический выбор самого широкоугольного физического сенсора фронталки для максимального охвата лица и окружения.
* **🔒 Локальная галерея инцидентов:** Встроенный просмотрщик видео и фото, возможность сохранить медиа в галерею или поделиться им.

## 🚀 Установка и настройка

1. Скачайте актуальный APK из раздела [Releases](https://github.com/nedestr0y/nedestroyme/releases).
2. Установите APK и откройте приложение.
3. Выдайте требуемые разрешения:
    * **Камера** и **Микрофон** (для фиксации видео/фото со звуком).
    * **Геолокация** (для определения координат взлома).
    * **Администратор устройства** (системное право для перехвата неудачных попыток ввода пароля).
4. *(Опционально)* Настройте Telegram-уведомления:
    * Создайте бота в Telegram через [@BotFather](https://t.me/BotFather) и скопируйте токен.
    * Узнайте свой Telegram ID через [@userinfobot](https://t.me/userinfobot).
    * Вставьте токен и ID в настройках приложения и нажмите «Отправить тестовое сообщение».

> ⚠️ **Важно для пользователей из РФ:** Так как API Telegram может блокироваться, убедитесь, что на телефоне включен VPN, а приложение `nedestroyme` добавлено в список туннелирования (Split Tunneling).
